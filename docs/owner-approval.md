# سجل موافقة المالك — Phase 1

## القرار الحالي

سجّل المالك موافقته: **«أوافق»** على توصيات **D01–D04 وD09**، وعلى **نموذج D07** الذي يجعل ولي الأمر يدير ملف الطفل **من دون دخول مستقل للقاصر**. هذه الموافقة تسمح ببدء Phase 1 وفق خارطة الطريق المرجعية في:

`/workspace/phase0-revision/elm-wa-amal-phase-zero-plan/docs/implementation/roadmap.md`

لا تغيّر هذه الوثيقة ملفات الخطة الأصلية، ولا تعني أن أي تكامل أو سياسة صار نهائياً أو مختبراً.

## حالة القرارات

| القرار | الحالة | القيد العملي |
|---|---|---|
| D01–D04 | **معتمد** | يوجّه التصميم والنطاق وفق التوصيات؛ لا يثبت تنفيذاً أو قبولاً تشغيلياً. |
| D09 | **معتمد** | يوجّه تصميم الوقت/الجدولة؛ لا يثبت اختباراً فعلياً. |

| D05 وD06 وD08 وD10 وD11 | **pending** | لا تُحوّل إلى افتراضات أو قرارات hard-coded، ولا تُعلن كميزات جاهزة. |

## ما يحق لـ Phase 1 بناؤه

النطاق موقع عام ثنائي اللغة فقط: **Next App Router + React + TypeScript strict + Tailwind**، بمسارات `/ar` و`/en`، وواجهات:

`/programs`، `/packages`، `/learning`، `/faq`، `/contact`، `/privacy`، `/terms`.

يجب أن يكون التصميم **RTL/LTR وmobile-first**، وأن يعرّف حالات `loading` و`error` و`not-found` و`contact unavailable`. صفحات السياسات **ملخص مراجعة** وليست نصوصاً قانونية نهائية.

## محظورات صريحة

- لا pseudo-login، ولا جمع نماذج/بيانات، ولا WhatsApp نشط، ولا نشر أرقام تحويل أو اتصال.
- لا `auth` أو Supabase أو payment أو migrations أو import لبيانات/قرآن أو Zoom أو storage أو real data.
- لا تغيير في `index.html` الأصلي: يظل محفوظاً، مع نسخة التوثيق في `docs/baseline`.
- لا commit أو deploy أو تعديل للبيئة الحية.
- لا يُدّعى تحقق رابط أو محفظة، ولا اختبار أو نجاح اختبار، قبل أن يقدم المنفذ دليلاً قابلاً للمراجعة.

## قراءة الحالة للتوثيق

- **مصمم:** المتطلبات والقرارات أعلاه وما تصفه خارطة الطريق.
- **أساس Phase 1 مخطط/مهيأ:** هيكل الموقع العام ومساراته وحالات الواجهة المستهدفة؛ يظل ذلك planned foundation إلى أن يثبته المنفذ بدليل.
- **منفذ:** لا تُسجّل هذه الصفة إلا بدليل مصدر/تسليم واضح من المنفذ، ولا تستنتج من هذه الموافقة.
- **مختبر:** نتائج التنفيذ الفعلية، لا الموافقة وحدها، مرجعها [تقرير المرحلة الأولى](phase-1-report.md) والسجلات المرتبطة به؛ الاختبار المحلي لا يثبت جاهزية تشغيلية أو تحقق خدمات خارجية.

## بوابة القبول

لا يوجد اكتمال لمرحلة قبول تشغيلي: **قناة التواصل، والهوية/الحماية، والنصوص النهائية، ونشر approval ما زالت unresolved**. موافقة «أوافق» هنا موافقة نطاق وقرار مرحلة، وليست تفويضاً لإطلاق، أو onboarding لأطفال حقيقيين، أو نشر إنتاجي.
