# علم وعمل — نتيجة تنفيذ المرحلة الأولى محليًا

**النتيجة:** نُفّذت نسخة الموقع العام للمراجعة داخل `source-review` فقط: ثماني صفحات بالعربية وثماني بالإنجليزية، بتصميم يبدأ بالهاتف واتجاهَي RTL/LTR. نجحت اختبارات النسخة المصححة. هذه ليست جاهزية إطلاق: التواصل غير مفعّل حتى التحقق، والشروط والخصوصية مسودتا مراجعة، والحسابات والدفع والجدولة والتقارير لم تُنفّذ.

لم يُنشأ commit أو push أو نشر، ولم تُشغّل migrations أو تُعدّل خدمات خارجية أو الموقع الحي. لا بيانات مستخدمين أو أطفال حقيقية ولا مفاتيح خدمات. بقي `index.html` الأصلي دون تغيير؛ تطابقه مع النسخة المحفوظة مثبت في [سجل البصمات](checks/baseline-sha256.txt).

## ما يمكن مراجعته الآن

المسارات `/ar` و`/en`، وتحت كل منهما: `programs`، `packages`، `learning`، `faq`، `contact`، `privacy`، `terms`. تبديل اللغة يحافظ على الصفحة ويحمّل مستندًا بالاتجاه واللغة الصحيحين من الخادم؛ الصفحات الأساسية تعمل أيضًا دون JavaScript. رابط تخطّي المحتوى، قائمة الهاتف، الأسئلة القابلة للفتح، وحالات التحميل والخطأ وعدم العثور موجودة.

الباقات مطابقة: **360 ريالًا = 8×60 دقيقة** للحفظ والفهم العام للمعاني؛ **500 = 8×60** للحفظ ونور البيان والفهم العام للمعاني؛ **650 = 8 حصص حتى90 دقيقة** للحفظ ونور البيان والتجويد، دون توريث وعد المعاني. تظهر ملخصات السياسات التي اعتمدها المالك مع تمييزها عن تنفيذ برمجي أو عقد نهائي.

صفحة التواصل تعرض سبب عدم الإتاحة، دون زر واتساب فعال أو رقم محفظة أو تعليمات تحويل أو نموذج بيانات. لم أختبر الرابط المورّد ولا ملكية المحفظة أو علامتها. لم تُنشأ صفحات دخول/تسجيل وهمية؛ مساراتها ترجع **HTTP404** إلى أن تُنفّذ في مرحلة مصرح بها.

التقنية: Next.js16.4.2، React19.3.1، TypeScript5.9.3 بوضع strict، Tailwind4.3.3 وقاموس محتوى متوازٍ. الاعتماديات مثبتة في lockfile. الهوية اللونية الحالية محفوظة؛ الزخرفة محلية بخواص CSS وخطوط النظام، دون صورة أو نص قرآن أو مادة تعليمية مستوردة.

## الفحوص التي شُغّلت فعلًا

| الأمر أو الفحص | النتيجة النهائية والدليل |
|---|---|
| `npm run typecheck` | نجاح؛ [السجل](checks/typecheck.log). |
| `npm run lint` | نجاح دون تحذيرات؛ [السجل](checks/lint.log). |
| `NEXT_TELEMETRY_DISABLED=1 npm run build` | نجاح بناء نسخة الإنتاج **محليًا**؛ [السجل](checks/build.log). |
| `npm audit --json` | صفر تنبيهات معلنة في الفحص النهائي؛ [التقرير](dependency-audit.json). ليس ضمانًا لخلو الحزم من كل عيب. |
| `npm run test:e2e` | **76 حالة ناجحة، صفر فشل أو تخطٍّ أو flaky**، عبر Chromium للهاتف وسطح المكتب، في27.6 ثانية؛ [السجل](checks/e2e.log) و[النتيجة الآلية](test-results.json). |
| `git diff --check` | نجاح دون أخطاء مسافات. |
| `cmp index.html docs/baseline/index.html` | تطابق؛ الصفحة الأصلية لم تتغير. |
| فحص HTTP محلي | الرئيسية200، ومسار دخول غير منفذ404؛ يؤكده أيضًا E2E. |

تشمل الاختبارات الصفحات الست عشرة عند عرض375 و1440 بكسل، وفحوصًا إضافية بعرض320 و768. تحققت من دقة الباقات، وحفظ المسار عند تغيير اللغة، و`lang/dir`، وعدم تجاوز العرض، ولوحة المفاتيح وتخطّي المحتوى وفتح الأسئلة، وتقليل الحركة، وغياب نماذج جمع البيانات والروابط التشغيلية غير المعتمدة، وعدم طلب موارد خارجية عند تحميل الصفحات، ورؤوس المعاينة. نجحت فحوص axe الموسومة WCAG A/AA في تركيبات الصفحات/العرض المختبرة؛ **هذا ليس شهادة مطابقة WCAG**.

حُفظت ثماني لقطات تحت `previews/`؛ راجعت بصريًا عينات من الرئيسية والباقات على الهاتف وسطح المكتب، منها [باقات الهاتف العربية](previews/mobile-ar-packages.png) و[الرئيسية الإنجليزية للهاتف](previews/mobile-en-home.png) و[الباقات الإنجليزية لسطح المكتب](previews/desktop-en-packages.png). لا تُعد محاكاة العرض اختبارًا لهاتف فعلي.

### ما أُصلح أثناء الاختبار

أظهرت الجولة الأولى60 نجاحًا و4 حالات فشل في تغيير `lang/dir` عند التنقل بين اللغتين. صُحّح رابط اللغة ليعيد تحميل المستند، ونجحت الحالات في الجولة النهائية. عولجت أيضًا استجابة200 لصفحة مفقودة في العرض المتدفق، وأصبح اختبار404 صريحًا. [سجل الجولة الأولى](checks/e2e-first-run.log) محفوظ ولا يُعرض كنجاح نهائي.

أظهر الفحص الأول خمس تنبيهات عالية في سلسلة أدوات lint التطويرية المرتبطة بـ`braces`. استُبدلت سلسلة إعداد الفحص بأدوات ESLint/TypeScript/React Hooks متوافقة ومثبتة، بدل تجاهل التنبيهات أو خفض Next.js. الفحص النهائي صفر تنبيهات.

## حدود الدليل والأمان

فُحصت الواجهة محليًا فقط. لا اختبار Auth/RLS أو عزل حسابات أو دفع أو بريد أو WhatsApp أو Zoom أو قاعدة بيانات، لأنها غير موجودة في هذه المرحلة. حالات التحميل والخطأ البرمجية موجودة، لكن لم أحقن فشلًا مصطنعًا أو أزعم اختبار استعادة إنتاجية؛ حالة عدم الإتاحة والـ404 اختُبرتا. لا توجد حالة «نجاح إرسال» مخترعة، لعدم وجود نموذج إرسال أصلًا.

لا اختبار قارئ شاشة فعلي أو Safari/Firefox أو جهاز مادي أو تدقيق اختراق أو أداء/استعادة نسخ احتياطية. رؤوس `noindex` ومنع التضمين و`nosniff` وتقييد صلاحيات الكاميرا والميكروفون والموقع أساسية للمعاينة، وليست تقوية إنتاج مكتملة. CSP ذي nonce وتهيئة الاستضافة والمراقبة والتقوية مراجعات لاحقة؛ لا نخلط غياب backend موصول بغياب أي metadata تقنية افتراضية للخادم.

## ما لا يزال يحتاج المالك

- **D05:** التحقق من وجهة واتساب وملكية/تسمية المحفظة واتفاقات EGP والطريقة الدولية قبل تفعيل التواصل أو أي تعليمات دفع.
- **D06:** تسمية مالك الحساب الإداري والمراجع المالي وخطة التحقق/MFA؛ لا bootstrap حقيقي الآن.
- **D07 جزئيًا وD08:** نموذج ولي يدير ملف الطفل بلا دخول مستقل معتمد؛ إجراءات التحقق والموافقة والسحب والدعم والحماية، والاختصاص القانوني ومنطقة البيانات والاحتفاظ/المحو ما زالت بوابات قبل أي طفل أو بيانات حقيقية.
- **D10:** مصدر القرآن وحقوقه والترقيم والمواد التعليمية والمقياس والمراجع التربوي؛ لم يُستورد شيء منها.
- **D11:** ملكية الخدمات والميزانية والمسؤولون والطيار المحدود، وموافقة النشر المستقلة.

**خطوة القبول الحالية:** مراجعة المالك للنصوص والهوية والعرض المحلي وتحديد قناة تواصل متحققة. D01–D04 وD09 معتمدة، لكن لا يحوّل ذلك القرارات المعلقة إلى اعتماد، ولا يبدأ تلقائيًا مرحلة ثانية أو إطلاقًا. التنفيذ العام جاهز للمراجعة المحلية، وليس قبولًا تشغيليًا نهائيًا للمرحلة أو للموقع.
