# خطة تطبيق الأكاديمية المحلي

## التدقيق

المشروع Next.js 16 / React 19 / TypeScript strict وTailwind. الموقع ثنائي اللغة قائم في `/ar` و`/en` بسبع صفحات فرعية. لا توجد لوحات تعليمية أو دخول تشغيلي. توجد واجهات Phase 2 محمية ومعطلة افتراضيًا، وSQL/RLS وحاضنات اختبار محلية للهوية والدفع. تُحفظ هذه البنية ولا نستبدلها ولا نعدّل قاعدة مزوّد مجهزة.

قُرئ البرومبت المعتمد كاملًا وREADME وخارطة الطريق ومخطط قاعدة البيانات والسياسات التشغيلية ووثائق الدفع المحلي. الموافقة الجديدة توسّع التنفيذ من الموقع والدفع إلى حلقة تعليمية محلية فعلية؛ تقارير المراحل القديمة تاريخية وليست نطاق العمل الحالي.

## التنفيذ

1. الحفاظ على صفحات الموقع والباقات؛ تحديث الهوية بالأخضر والأبيض والذهبي وإضافة صفحات التعريف والمعلمين والتسجيل التجريبي وروابط مساحة الأكاديمية.
2. إنشاء محوّل بيانات محلي منفصل مع سجلات اصطناعية فقط، محفوظة خادميًا لكل جلسة مراجعة. تفعيل صريح `ACADEMY_DEMO=synthetic-only`؛ لا اعتماد إداري حقيقي ولا دخول طفل. اختيار شخصية تجريبية معلن ليس مصادقة.
3. بناء مساحة واحدة مترابطة بأربع وجهات: ولي الأمر، الطالب البالغ، المعلم، الإدارة. دورة التقييم والإسناد والخطة والجدولة والحضور والتقييم والواجب والتقرير المنشور. صلاحيات وفصل الملاحظات الخاصة وفحص التعارض على الخادم.
4. عرض حالة التكاملات بصدق: Zoom والدفع والرفع والبريد والتشغيل المستضاف غير مفعلة؛ لا بيانات حساسة أو أرقام محفظة عامة ولا تحويل SAR/EGP. لا نص قرآن أو ملفات مناهج. المراجع الرقمية أمثلة يراجعها المعلم وليست مصحفًا معتمدًا.
5. اختبارات وحدة وصلاحيات وHTTP/متصفح، RTL/LTR وهاتف وسطح مكتب، ثم typecheck/lint/build واختبارات التراجع المناسبة. توثيق النتائج والبوابات المتبقية.

## سلامة البيانات

تعليم فردي فقط. ملفات القاصرين مرتبطة بولي تجريبي بلا حساب طفل. لا نشر أو commit أو push أو migrations مستضافة أو Zoom API. الثمن 360/500/650 SAR والمحتوى والمدد الأصلية محفوظة؛ باقة 360 للحفظ فقط مع الفهم العام الموجود في العقد، لا علوم شرعية إضافية. لا تفعيل مالي من الحلقة التعليمية ولا استهلاك استحقاق مالي وهمي.
