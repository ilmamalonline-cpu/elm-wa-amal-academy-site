# علم وعمل: تطبيق تعليمي محلي يعمل

أصبح المشروع يتضمن تطبيقًا تفاعليًا متصلًا، وليس واجهات عرض فقط: **تقييم أولي ← إسناد معلم ← خطة فردية ← حجز حصة ← توثيق وتقييم ← واجب ومراجعته ← تقرير للأسرة**. يعمل ببيانات اصطناعية محفوظة على الخادم المحلي، مع أربع شخصيات للمراجعة: ولي أمر، طالب بالغ، معلم، وإدارة.

هذه دفعة تعليمية عمودية قابلة للتجربة، **وليست منصة جاهزة للإطلاق أو مصادقة إنتاجية**. اختيار شخصية الإدارة متاح عمدًا للمختبر؛ ليس إنشاء حساب إداري أو منح صلاحية حقيقية. لا تُدخل بيانات شخصية ولا تُنشر منافذ هذا الوضع.

## ما تغيّر

حُفظ Next.js 16 وReact 19 وTypeScript الصارم والموقع الثنائي اللغة والبنية السابقة للاختبارات والهوية والدفع المحلي. سُبقت التعديلات بمراجعة README ووثائق المرحلة صفر والسياسات ومخطط البيانات ووثائق الدفع والبرومبت المعتمد. الخطة المختصرة في [خطة التنفيذ](academy-implementation-plan.md)؛ الوثائق القديمة أصبحت سجلًا تاريخيًا، لا قيدًا يلغي الموافقة الجديدة.

أُضيفت مساحة أكاديمية واحدة بسبعة أقسام مترابطة: النظرة العامة، الطلاب والخطط، الحصص، الواجبات، التقارير، الإشعارات والسجل، والخدمات والاشتراك. تعمل الحوارات والحفظ والبحث والمرشحات والترقيم والتوقيت وإعادة الضبط. تعكس العدادات السجلات الفعلية داخل العالم الاصطناعي، ولا تدّعي إحصاءات تسويقية أو إتقانًا آليًا.

تستطيع الإدارة تسجيل التقييم والإسناد وسحبه والإشراف على الحجوزات والسجل؛ ويستطيع المعلم حفظ خطة أو مسودة، وتوثيق الحضور، وإضافة درجات بشرية 1–5 أو «لم يُقيّم»، ومرجع رقمي وملاحظات وواجب، ثم نشر التقرير ومراجعة الرد. ترى الأسرة السجلات المنشورة فقط، وتستطيع الحجز والنقل والإلغاء المسموح وتسليم الواجب النصي وقراءة التنبيهات. الطالب البالغ يدير ملفه الفردي؛ الطفل ملف مرتبط بولي الأمر **بلا دخول مستقل**.

الهوية أخضر/أبيض/ذهبي مع سطح عاجي وتفاصيل هندسية مقتصدة. استُخدم IBM Plex Sans Arabic محليًا دون اتصال خط خارجي، مع [إشعار المصدر والترخيص](../public/fonts/ibm-plex-sans-arabic/SOURCE.md). أُضيفت صفحات التعريف والمعلمين والتسجيل التجريبي، مع إبقاء الباقات ومحتواها: 360 و500 و650 SAR، وثماني حصص فردية، و60/60/حتى90 دقيقة. لا تحويل للعملات أو رقم محفظة عام أو تحصيل.

## المسارات التي تعمل

- `/ar` و`/en`: الموقع العام.
- `/{locale}/about`، `teachers`، `enrollment`، `programs`، `packages`، `learning`، `faq`، `contact`، `privacy`، `terms`.
- `/ar/workspace` و`/en/workspace`: التطبيق المحلي للأدوار الأربعة، مع تبديل اللغة على مستوى المستند RTL/LTR.
- `/api/academy-demo`: API محلي معلن للاختبار؛ مغلق افتراضيًا، وليس endpoint لحسابات حقيقية.

## جرّبه بخطوات قصيرة

```bash
npm run dev:academy -- --port 3000
```

افتح `http://127.0.0.1:3000/ar/workspace`. يوجد طفل تجريبي وبالغ بخطة وإسناد جاهزين للمراجعة. لإنشاء رحلة جديدة اختر ولي الأمر، ثم «الطلاب والخطط» و«طلب تعلم تجريبي»؛ يظهر طفل اصطناعي جديد دون طلب اسم أو هاتف. بدّل إلى الإدارة لتقييمه وإسناده، ثم المعلم لحفظ خطة منشورة، ثم الولي لحجز موعد ونقله أو إلغائه.

لاختبار التقرير والواجب، اختر المعلم ووثّق **جلسة التدريب الماضية**؛ تُحجب المسودة عن الأسرة حتى نشرها. بدّل إلى الولي لتسليم الرد، ثم المعلم لمراجعته، ثم الولي لرؤية التقرير والمراجعة. لا يسمح النظام بتقييم حصة مستقبلية أو قبل نهايتها.

```bash
npm run build
npm run start:academy -- --port 3000
# في جلسة أخرى للتحقق من الوضع الافتراضي المغلق:
npm run start -- --port 3003
# ثم:
ACADEMY_DISABLED_TEST=synthetic-only npm run test:e2e -- --reporter=list --output=test-results/academy-final
```

أوامر `dev` و`start` العادية لا تفعّل API التجريبي. أوامر `:academy` تضبط `ACADEMY_DEMO=synthetic-only` وتربط الخادم بـ127.0.0.1. لا توجد بيانات اعتماد مطلوبة لهذا المحوّل.

## حماية البيانات داخل التجربة

يفحص الخادم الدور وعلاقة الولي والإسناد الفعال؛ لا يعتمد على إخفاء الأزرار. لا يغيّر header أو cookie لدور مزعوم هذه الصلاحيات. cookie يحمل معرّفًا عشوائيًا HttpOnly/SameSite=Strict، والدور المختار محفوظ خادميًا. الوصول بلا تفعيل صريح يُرجع503؛ وتُرفض أصول الويب المختلفة والطلبات غير المطابقة والحجوم الكبيرة. الأخطاء الداخلية لا تعرض تفاصيل ملفات الخادم.

عالم كل جلسة منفصل في `/tmp/elm-wa-amal-academy-synthetic` خارج المستودع، بصلاحيات مجلد700 وملفات600. تُنفّذ التغييرات كاملة أو لا تُحفظ، وتُسلسل معاملات العملية لمنع سباق الحجز. يمنع الخادم التعارض والمدة غير المناسبة، ويحجب المسودات والواجب غير المنشور والملاحظات الخاصة، ويسحب وصول المعلم مع الإسناد.

قاعدة تغيير الموعد العائلية قبل24 ساعة محاكاة محلية، مع استثناء إدارة معلن؛ وسقف8 حجوزات غير ملغاة لكل ملف سعة اختبار، **لا دفتر استحقاقات أو خصم مالي**. لا تدّعي معاملات الملفات مقاومة التزامن بين عدة خوادم. إعادة الضبط تعيد أمثلة هذا العالم فقط؛ ومسح cookie لا يمحو ملفات العالم تلقائيًا، ولا توجد هنا سياسة احتفاظ إنتاجية معتمدة.

## ما لم يُفعّل

**Supabase المستضاف:** لم يُتصل بقاعدة البيانات ولم يُطبّق schema أو migration مستضاف. مسار DB المباشر المتاح سابقًا IPv6-only، ولا توجد بيانات Session Pooler معتمدة. يلزم وصول آمن مدعوم، ثم ربط سجلات التعليم بمصادقة حقيقية وعلاقات الولي وسياسات RLS واختبارات متعددة الحسابات قبل التشغيل.

**Zoom:** لم تُستخدم أي قيمة سرية منشورة في محادثة، ولم يُستدعَ API حي. يلزم تدوير Client Secret عبر مسار آمن أولًا. زر الدخول الحقيقي للحصة معطّل. مواد القرآن والتجويد ونور البيان تبقى لدى المعلم داخل Zoom؛ لا نصوص قرآن أو ملفات مناهج مستوردة.

**الدفع والاشتراكات والرفع والبريد:** لم يحدث دفع أو تفعيل اشتراك أو رسالة خارجية أو رفع ملف. تبقى واجهات المرحلة السابقة مغلقة افتراضيًا؛ اختبارات الدفع وحدها تستخدم PostgreSQL محليًا اصطناعيًا مستقلًا، ولا تعني ربطًا ماليًا فعليًا. إشعارات الأكاديمية داخل التطبيق فقط.

المراجع التعليمية محصورة بأمثلة رقمية للسور112–114 ضمن حدودها؛ ليست قاعدة مصحف معتمدة. الواجب نصي فقط. لا تقييم تلاوة آلي، ولا تتبّع إتقان/احتفاظ طويل المدى، أو تسجيل صوتي، أو استيراد مناهج، أو دعم مراسلات حقيقي. جدول المواعيد قائمة فتحات اصطناعية لا تقويم توافر إنتاجي؛ تحرير توافر المعلمين وإدارة البرامج والاشتراكات والدعم خارج هذه الدفعة. يوجد هدف ومرجع للخطة وسجل تقييمات، لا محرك ILP شامل بموافقات ومراحل متعددة.

## نتيجة الفحوص

اجتاز بناء Next و`typecheck` و`lint` وفحص `git diff --check` دون أخطاء.

| الفحص | النتيجة |
|---|---|
| المحوّل التعليمي: العلاقات، الخصوصية، المعاملات، الدرجات، الحجز المتزامن | 8 ناجحة |
| Playwright على نسخة البناء: الموقع والتطبيق وHTTP والوضع المغلق، سطح مكتب وهاتف وعربي/إنجليزي | 102 ناجحة، صفر إخفاق أو تخطي |
| تحصين المرحلة السابقة دون خدمات مستضافة | 40 ناجحة: 34 + 6 |
| الدفع الاصطناعي السابق في PostgreSQL محلي مؤقت مستقل | 29 ناجحة: 19 + 10 |

شملت فحوص المتصفح الرحلتين التعليميتين والحفظ بعد إعادة التحميل، واختبارات axe الآلية، والتركيز ولوحة المفاتيح وإغلاق الحوار، وRTL/LTR، وعروض320/375/768/1024/1440، والحركة المخفّضة، والموقع العام دون JavaScript. هذه أدلة آلية ومراجعة بصرية، لا شهادة مطابقة شاملة لإمكانية الوصول.

سجل الجولة النهائية: [production-browser-final.log](checks/academy/production-browser-final.log). نتائج البناء والأنواع والفحص والوحدات والتراجع في `docs/checks/academy/`. تحتفظ السجلات الأولية بإخفاقاتها لأمانة التوثيق؛ عولج تطبيع عناوين Next والتباين، وصُحّحت استعلامات الاختبار ووجهة آثار التشغيل المتوازي قبل نجاح الجولة النهائية.

معاينات ناتجة من الاختبارات: [لوحة عربية على سطح المكتب](previews/academy/desktop-ar-overview.png)، [لوحة عربية على الهاتف](previews/academy/mobile-ar-overview.png)، [تقرير منشور بالإنجليزية](previews/academy/desktop-en-published-report.png). صور الموقع العام والباقات في `docs/previews/`؛ كلها بيانات اصطناعية.

## الأولويات التالية

1. توفير مسار Supabase آمن مدعوم وربط المصادقة وRLS والسجلات التعليمية، مع فصل بيئات الاختبار والإنتاج وسياسة احتفاظ معتمدة.
2. استكمال اعتماد تشغيل الطفل والموافقة والسياسات التجارية، ثم تقويم التوافر الحقيقي وخطط المراجعة والاحتفاظ المفصلة.
3. بعد تدوير الأسرار والتحقق: توصيل Zoom، ثم البريد/التنبيهات والرفع الخاص عند اعتماده. يبقى الدفع مشروع تفعيل مستقل بأحداث مالية موثقة.

لم يحدث نشر أو commit أو push. التطبيق والخدمات التجريبية شُغّلت محليًا فقط.

## إضافة لاحقة: تجهيز معاينة Vercel دون تنفيذ نشر

أُضيف محوّل `browser-preview.ts` يعيد استخدام النموذج والواجهات نفسها داخل المتصفح حصريًا في `VERCEL_ENV=preview`. الحفظ في `sessionStorage` لا في `/tmp`، ولا استدعاء API أو بيانات اعتماد أو حالة مشتركة. هذا محوّل عرض تفاعلي اصطناعي فقط، لا مصادقة؛ بيانات الملاحظات الاصطناعية قابلة لفحص صاحب المتصفح رغم حجبها عن واجهة الأسرة. تعليمات التشغيل المحلي السابقة تخص محوّل الخادم الذي بقي loopback-only.

تظل Production والخدمات الأصلية مغلقة على Vercel حتى مع أعلام الاختبار. اجتازت الإضافة 12 اختبار نموذج/تخزين، و92 اختبار متصفح للهاتف وسطح المكتب (12 للمعاينة و80 للموقع العام)، و40 اختبار تحصين قديمًا، والبناء والأنواع وlint. أُصلح محدد اختبار كان يختار طفل الأسرة الاصطناعية الأخرى عند قراءة العالم الخام بدل العرض المقيّد؛ الجولة الأخيرة ناجحة. فحوص PostgreSQL السابقة لم تُكرر ولا تعني اتصالًا مستضافًا.

تفاصيل الدفعة وحدود التخزين والفرع المقترح في قسم المعاينة أعلى README، والقائمة الدقيقة في `docs/changed-files.txt`. السجلات التاريخية بقيت على القرص واستُبعدت من الرفع؛ لم يحدث commit أو push أو إنشاء فرع أو نشر أو تغيير حساب/خدمة. يلزم اعتماد المالك للحمولة وفرع المعاينة قبل أي إجراء خارجي.
